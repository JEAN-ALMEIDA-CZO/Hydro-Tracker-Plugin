# Hydro-Tracker-Plugin
O intuito do Hydro Tracker é simples: manter-te a beber água ao longo do dia sem teres de pensar nisso. A partir do teu perfil calcula uma meta diária personalizada, distribui-a pelas horas acordado e faz a contagem decrescente na tecla até ao próximo copo — tornando a hidratação num hábito, não numa tarefa.
